# 漫游岛

一座只属于你的小岛，用来记录**生活、学习、工作与灵感**。

它是一个单文件网页应用：没有账号、没有服务器、没有构建步骤。打开 `index.html` 就能用，所有数据保存在你当前浏览器的本地存储里。

---

## 如何打开

**最简单**：双击 `index.html`，用 Chrome / Edge / Safari 打开即可。

如果浏览器对本地文件限制较多（例如某些环境下 `localStorage` 不可用），可以在本目录启动一个本地静态服务器：

```bash
# 任选一种
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080`。

> 建议把它固定到浏览器书签栏；也可以在 Chrome / Edge 里用「创建快捷方式 → 在窗口中打开」，把它当成一个独立小应用。

## 岛上的五个区域

| 区域 | 用途 |
| --- | --- |
| **岛屿** | 首页。问候、快速记录、今日概览、半年记录热力图、最近脚印 |
| **生活** | 日期、天气、心情、正文、标签。适合记日常小事、情绪、见闻 |
| **学习** | 主题、时长、收获笔记、标签。带本周时长柱状图和累计统计 |
| **工作** | 待开始 / 进行中 / 已完成 三列看板，支持优先级、截止日期、逾期提醒 |
| **灵感** | 卡片式念头收集，先记下来，不急着实现 |

### 一些细节

- **快速记录**：首页输入框可切换「生活 / 学习 / 工作 / 灵感」，回车即存。
- **连续漫游天数**：任何区域当天有记录就算一天，断掉会重新计数。
- **潮汐热力图**：桌面端显示最近半年，手机端自动收成最近 14 周；颜色越深代表当天记录越多。
- **编辑**：鼠标悬停在记录卡片上，点「编辑」会回到顶部表单修改；手机上操作按钮常显。
- **键盘快捷键**：`n` 聚焦快速记录，`/` 聚焦搜索框，`Esc` 关闭设置弹窗。
- **搜索**：各区域右上角可搜索正文、标题、标签、心情等。

## 数据与备份（重要）

数据保存在浏览器的 `localStorage` 中，键名为 `roaming-island:v1`。

这意味着：

- 换电脑、换浏览器、清理浏览器缓存、使用无痕模式，数据都**不会自动跟着走**。
- 建议每隔一段时间点右下角「数据与备份」→「导出备份」，会下载一个 JSON 文件。
- 在新设备上打开页面，用「导入备份」选择该 JSON 即可恢复（会覆盖当前数据，导入前有确认提示）。
- 也可以「导出 Markdown」，得到一份按日期整理的纯文本记录，方便归档或粘贴到别处。

> 数据只在这台设备上，不上传任何服务器。

## 想改点什么

### 改称呼和岛语

打开页面 → 右上角设置图标 → 修改「你的称呼」「岛语」「启程日」。

### 改配色

打开 `index.html`，找到 `:root` 里的 CSS 变量：

```css
--paper:#F4EFE2;      /* 纸张底色 */
--ink:#1E2E29;        /* 主文字 */
--sea-deep:#1F433C;   /* 深海报，主按钮/标题 */
--sea:#3F7268;        /* 海水 */
--coral:#C9705A;      /* 珊瑚色强调 */
--life:#C97B5A;       /* 生活分类色 */
--study:#4F7F74;      /* 学习分类色 */
--work:#5B6B93;       /* 工作分类色 */
--idea:#BE9439;       /* 灵感分类色 */
```

改完刷新即可。

### 改字体

`--serif` 控制标题字体，`--sans` 控制正文字体。默认优先使用系统里的思源宋体 / 宋体，Windows 上会回退到 SimSun，macOS 上是 Songti SC。

## 部署到网上

因为它是纯静态单文件，可以把整个 `roaming-island` 目录拖到任意静态托管：

- GitHub Pages
- Vercel / Netlify（直接拖拽文件夹）
- 自己的服务器 / 对象存储

部署后注意：每个浏览器仍然各自独立保存数据，**不会跨设备同步**。如果以后需要多设备同步，就需要加一个后端或云数据库（见下）。

## 后续可以怎么长大

如果这座岛用顺手了，可以考虑：

1. **PWA**：加 `manifest.json` 和 Service Worker，让它可以离线打开、安装到桌面/手机主屏。
2. **图片附件**：生活记录支持拖入照片（IndexedDB 存储）。
3. **日历视图**：按月查看每天有没有记录、点某一天回看。
4. **标签筛选**：点击标签只看同类记录。
5. **云同步**：Supabase / Firebase 之类的轻后端，实现多设备同步。
6. **周报自动生成**：把一周的记录汇总成一段回顾。
